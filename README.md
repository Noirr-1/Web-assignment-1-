# Noir N — Freelance Platform

Noir N is a multi-page freelance platform website
designed using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Formspree
- Responsive design
- CSS keyframe animations

No JavaScript or Tailwind CSS is used.

## Formspree Setup

1. Visit https://formspree.io/
2. Create an account.
3. Create a new form.
4. Copy your Formspree endpoint.
5. Open contact.html.
6. Replace YOUR_FORM_ID in the form action.

Example:

<form
    action="https://formspree.io/f/YOUR_FORM_ID"
    method="POST"
>

After replacing the endpoint, test the contact form.

## How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Navigate through the website using the navbar.

## GitHub Pages Deployment

1. Create a GitHub repository.
2. Upload all project files.
3. Open repository Settings.
4. Select Pages.
5. Select the main branch.
6. Save the deployment settings.
7. Open the generated GitHub Pages link.
